## 📋 About

**SCP GEN** is the AI intelligence layer of the SCP ecosystem. Powered by a Node.js backend and Python automation engine, it delivers a broad spectrum of capabilities — real-time screen capture, desktop action automation, world event monitoring, smart notes, and much more. GEN learns, adapts, and acts.

> 🧠 *50+ features. One assistant. Infinite possibilities.*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-org/scp-gen.git

# Navigate to the project
cd scp-gen

# Install Node.js dependencies
npm install

# Start the development server
npm run dev

# Or start in production mode
npm start
```

<br>

## 📁 Project Structure

```
scp-gen/
├── 📄 app.js                    # Main application server
├── 📄 server.js                 # Express server setup
├── 📄 actions.js                # Action automation engine
├── 📄 gen_automation.py         # Python automation scripts
├── 📄 index.html                # Web interface
├── 📂 notes/                    # Smart notes storage
├── 📂 recordings/               # Screen recording output
```
